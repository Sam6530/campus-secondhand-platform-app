## 2 技术架构

| 设计项 | 基线方案 | 关联决策 |
|---|---|---|
| 总体架构 | Vue 3前端与Java后端分离开发；后端采用Spring Boot模块化单体；MySQL持久化 | ADR-RB-01 |
| 工程环境 | Java 17、Spring Boot 3.5.7、MyBatis、MySQL 8、Vue 3.5、Vite 6 | [运行与配置说明](运行与配置说明.md) |
| 接口入口 | 浏览器统一访问`/api`，开发环境由前端代理，交付环境由同源入口转发 | Q-RB-02 |
| 身份安全 | Session登录、CSRF写操作保护、角色与对象归属校验、公开字段白名单 | ADR-RB-05 |
| 交易一致性 | MySQL事务、唯一有效占用、订单快照和统一锁顺序 | ADR-RB-02 |
| 幂等处理 | 重要写操作使用意图键和请求摘要保存稳定回执 | ADR-RB-03 |
| 通知机制 | 业务事务登记Outbox事件，事务提交后投递并支持重试 | ADR-RB-04 |
| 数据演进 | 数据库结构按顺序执行版本化迁移，升级脚本和校验信息随工程保存 | [数据与状态设计](数据与状态设计.md) |
| 验证方式 | 模块测试、接口测试、MySQL集成测试、浏览器场景测试和阶段回归 | [测试用例](../testing/测试用例.md) |

## 3 模块边界

| 模块 | 主要内容 | 主责 |
|---|---|---|
| 前端基础与用户页面 | 页面布局、请求封装、登录状态、物品和订单交互 | A |
| 交易与数据 | 物品、订单、交付、占用、数据库迁移和事务控制 | B |
| 社区与通知 | 收藏、评价、信誉、统计、Outbox和站内通知 | B |
| 身份与治理 | 注册登录、认证审核、账号限制、物品审核、举报和争议处理 | C |
| 沟通与管理 | 商品咨询、订单聊天、管理页面和治理操作入口 | C |
| 独立验证 | 契约核对、异常场景、数据库前后态、浏览器回归和阶段验收 | D |

跨模块调用通过明确的业务接口完成。身份上下文、订单状态、治理动作和通知事件使用统一契约；共享接口及数据结构由提供方和调用方共同维护。

## 4 阶段准入

阶段集成应同时具备以下内容：

1. 本阶段代码能够构建和启动；
2. 数据库迁移能够在新建数据库和升级数据库中顺序执行；
3. 前后端接口与OpenAPI保持一致；
4. 各成员提交对应的自测与交接材料；
5. D完成独立验证并形成阶段验收记录；
6. 设计、实现、任务和测试文档使用同一版本基线。

## 5 基线变更

需求、接口语义、事务边界、数据结构或运行依赖发生调整时，先在架构确认与决策记录中登记原因和影响，再同步更新接口、数据、阶段任务及测试内容。涉及已验收范围的调整应执行对应回归测试，并在新的版本基线上重新登记验收结果。
