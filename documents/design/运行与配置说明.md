# 运行与配置说明

版本0.2，2026-11-24。本文定义实现时要落实的环境和配置契约。具体安装版本、命令及启动脚本由V1工程任务验证后登记在implementation/README.md；这里列出统一方案和待登记的实际机器信息。

## 1 本机与局域网拓扑

各人本机运行前后端和独立合成数据库；联调机运行一套后端、数据库与图片存储，组员通过浏览器访问。建议前端开发端口5173、后端18080、数据库3306，实际冲突时共同调整配置和环境记录。

浏览器请求统一使用相对/api，由前端开发代理或交付入口转发到后端；前端不能连接MySQL。localhost表示访问者本机，局域网入口须使用联调机实际LAN地址。前后端同源入口优先，避免每个成员自行添加通配跨域和跨站Cookie设置。

数据库可原生或Docker运行，由Q-RB-01确认当前联调方式，不把需要命令启动误解为代码缺少数据库：仓库应带结构迁移与合成种子；运行中的MySQL数据保存在各环境独立存储。团队共享结构和种子，不共享某个人的容器可写层。

## 2 配置项候选

以下是用途约定，最终变量映射随工程实现锁定。

| 配置 | 用途及约束 |
|---|---|
| SERVER_PORT / SERVER_ADDRESS | 后端端口与监听；LAN联调才允许所需网卡访问 |
| DB_URL / DB_USERNAME / DB_PASSWORD | 各环境数据库地址与应用账号；不能出现在浏览器包或提交历史 |
| API_PROXY_TARGET | 前端开发代理目标，实际LAN地址由联调机提供；浏览器仍用/api |
| UPLOAD_DIR / UPLOAD_MAX_BYTES | 持久图片目录与上传上限；不使用开发者个人绝对路径写死到响应 |
| SESSION_TIMEOUT / COOKIE_SECURE | 会话有效期与传输参数；LAN HTTP和未来HTTPS使用相符配置 |
| NOTIFICATION_BATCH_SIZE / RETRY_INTERVAL | Outbox批次、退避与补投周期；重试不重新执行交易 |
| SEED_ENABLED | 仅明确的合成开发/测试库启用，不重置已有记录或真实账号 |

配置示例仅放无密钥样例；实际本机配置和密码排除版本控制。日志不打印口令、Session、CSRF令牌和认证原件。上传格式/数量/容量、输入长度等在接口评审时落实，服务端拒绝与前端提示保持一致。

## 3 启动与迁移责任

B提供后端构建、迁移序列、数据库健康检查及可重复初始化；C核身份/治理/聊天表和授权；A提供前端构建与代理；D在全新合成库和已运行库分别验证。共享启动脚本由当轮指定维护者合并，脚本职责清楚后再实现，不创建看似可运行的空脚本。

已执行迁移追加升级，不修改旧脚本。种子与正式迁移分开；常规启动不删库、不自动覆盖账号和图片。备份记录数据库版本、结构迁移版本和图片关联，恢复测试同时检查二者一致性。

## 4 实际环境登记与验证

V1准入登记联调负责人/机器、LAN地址、实际端口、操作系统、Node/Java/构建工具/MySQL版本、数据库名称及迁移版本、图片目录、配置样例位置和启动命令。成员账号映射与机器目前未指定，登记真实信息后使用。

检查顺序：依赖及配置就绪→MySQL可用→结构迁移→后端健康→前端构建/入口→新会话和CSRF→合成注册认证/交易→另一电脑访问→重启后数据与图片仍可读。运行结果关联TC-RB-28及对应阶段证据；性能TC-RB-29另登记数据量、硬件、负载、指标依据，不能用健康检查代替性能结论。
