# 阶段准入记录

版本1.0，2026-11-12。本文件记录各阶段开始实施时采用的共同输入和检查条件。

## 1 V1准入

| 检查项 | 准入内容 |
|---|---|
| 需求 | FR01—FR24、BR01—BR20及质量要求作为业务基线 |
| 架构 | 前后端分离、模块化单体、MySQL事务与统一接口入口 |
| 接口 | Session、CSRF、统一错误响应、物品与订单核心接口 |
| 数据 | 账户、认证、物品版本、订单快照、有效占用、交付、审计及Outbox |
| 任务 | TASK-V1-01—09覆盖共同准备、A/B/C实现和D验证 |
| 环境 | Java 17、Spring Boot、MySQL 8、Vue 3、Vite 6 |
| 测试 | 身份、发布审核、交易、聊天、幂等、权限及并发用例 |
