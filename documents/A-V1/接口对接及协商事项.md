# A V1接口消费与协商

输入为本地ba17471中的OpenAPI 0.2评审稿，副本openapi-input.yaml。此前Q/ADR状态原样保留。本次用户授权A前端制作，不伪造B/C接口接受记录。

| 页面 | 接口 | 关键约定 |
|---|---|---|
| 全站会话 | GET /me、POST /auth/register/login/logout | Session、CSRF；凭据不trim；切号清理草稿和在途响应 |
| 市场 | GET /items?q=&category=&page= | 数组、每页20候选；seller_id为公开引用，seller_verified来自后端，不写死已认证 |
| 我的发布 | GET /items/mine、POST /items、PUT /items/{id}、POST /items/{id}/withdraw | 发布与编辑带稳定Idempotency-Key；编辑带version；失败不清表单 |
| 认证与图片 | GET/POST /verifications、POST /assets?（multipart字段file、kind） | FormData由浏览器设boundary；kind为ITEM/VERIFY；5MB候选限制；私有读取由服务端授权 |
| 订单 | GET/POST /orders、POST /orders/{id}/{action} | accept/reject/deliver/confirm/cancel/remind独立语义；意图键；不接受客户端决定买方身份 |
| 详情 | GET /orders/{id}/details | {order,delivery:null或{actor_name,actor_id,created_at,note},reviews}；A V1只展示快照和交付 |
| 会话 | GET /inbox、GET/POST /messages?type=&object=&peer= | ITEM与ORDER分开；peer不是授权；终态只读，轮询重新查订单阶段 |
| 通知 | GET /notifications | 站内列表；通知故障不假报交易失败／成功，结果以本人订单查询为准 |

所有非GET由client带X-CSRF-Token。写入默认不自动重放；关键意图在同一页面未决期间按用户／路径／方法／内容区分。401/403重新同步身份，角色变化导致清理；服务端错误显示message，网络异常提示保留输入并查询或原样重试。错误后不主动换意图键。
