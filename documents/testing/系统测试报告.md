# 系统测试报告

报告日期：2026-11-12。测试对象为校园二手交易与物品流转平台V2集成基线。

## 1 测试范围

系统测试覆盖注册登录、校园认证、物品发布审核、搜索咨询、订单处理、交付确认、收藏评价、举报争议、治理统计、通知、图片资源、数据库迁移和运行入口。

质量属性覆盖功能正确性、权限与隐私、事务一致性、幂等与并发、可靠性、可恢复性、可理解性和局域网可运行性。

## 2 测试环境

- 后端：Java 17、Spring Boot 3.5.7、MyBatis；
- 前端：Vue 3.5、Vite 6、Microsoft Edge；
- 数据库：MySQL 8.0.39独立合成测试库；
- 访问方式：本机前后端同源代理及局域网入口；
- 数据：合成账号、物品、订单、争议、评价和通知。

## 3 测试结果

| 类别 | 结果 |
|---|---|
| 后端回归 | 53项通过 |
| MySQL集成与并发 | 4项通过 |
| 前端行为与构建 | 39项通过 |
| 真实HTTP及MySQL | 27组通过 |
| 浏览器业务场景 | 8组通过 |
| 数据库升级 | V5至V6升级及数据保持通过 |
| 启动与代理 | 配置、页面、接口代理、CSRF和停止流程通过 |

## 4 重点结论

- 单件物品保持唯一有效占用，订单、物品、交付和占用状态一致；
- Session、CSRF、对象归属和角色权限共同保护私有操作；
- 发布、下单、收藏、评价和通知具有明确的重复请求处理；
- 公开评价、图片及认证材料按照字段和资源权限访问；
- 争议补证、治理恢复和统计区间符合业务规则；
- 通知投递与业务提交分离，数据库升级保持既有记录；
- 前后端能够通过统一启动入口提供可访问的系统。

## 5 测试结论

V2集成基线的功能、接口、数据、权限、可靠性和运行入口验证通过。测试结果与[测试用例](测试用例.md)、[V1验证记录](V1验证记录.md)、[V2验证记录](V2验证记录.md)及[证据索引](../evidence/证据索引.md)保持对应。
